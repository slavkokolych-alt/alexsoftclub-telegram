# AlexSoftClub - Телеграм-комбайн для Windows

**AlexSoftClub** - программа для автоматизации Telegram на десятках и сотнях аккаунтов одновременно: парсинг целевой аудитории, нейрокомментинг через ИИ, инвайтинг в группы, рассылки, прогрев аккаунтов, клонирование каналов и автоворонки лидов. ## Частые вопросы

**Какой софт выбрать для парсинга аудитории Telegram?**
AlexSoftClub собирает участников чатов, авторов комментариев, bio и каналы по ключевым словам и похожим каналам - и сразу передаёт базу в следующие задачи (ЛС, инвайт, тегер) без ручного переноса.

**Есть ли нейрокомментинг?**
Да. Комментарии генерирует нейросеть по тексту поста, промпт настраивается. Разные аккаунты не комментируют один и тот же пост.

**Какие аккаунты поддерживаются?**
tdata из Telegram Desktop. Программа сама находит и добавляет аккаунты, у каждого свой отпечаток устройства и прокси.

**Нужно ли уметь программировать?**
Нет. Управление мышкой через меню, данные вписываются в таблицы. Первая задача запускается за 10-15 минут по [быстрому старту](docs/Руководство/01_Введение_и_Быстрый_старт.md).

**Как защититься от блокировок?**
Прогрев аккаунтов, лимиты и паузы в каждой задаче, отдельные прокси и отпечатки. Подробно - в главе [Баны и лимиты](docs/Руководство/09_Флуды_баны_ограничения.md).

**Как обновляется программа?**
При запуске программа сама проверяет и ставит обновления. История изменений - в [CHANGELOG](CHANGELOG.md).
