# 15. ИИ диалог аккаунтов - как работать (задача 23)

Практическая инструкция: что делает задача **23**, как настроить, запустить и проверить результат.

Промпты и файлы `Data/AI/` - в [главе 14](14_Промпты_для_ИИ.md).  
LLM API (URL, ключ, модель) - в [главе 13](13_Настройка_LLM_API.md).

---

## Что это за задача

**ИИ диалог аккаунтов** - это не личный менеджер по лидам. Это **оживление чата вашими аккаунтами**:

- несколько ваших аккаунтов пишут в **общий чат** (группу или обсуждения под каналом);
- чатов может быть много: список задаётся в таблице `23 0 ИИ диалог чаты`, аккаунты обходят их **по очереди, чат за чатом**;
- каждое сообщение генерирует нейросеть по промптам из `Data/AI/`;
- аккаунты могут отвечать друг другу и на чужие реплики в чате;
- при включённой **дуге** разговор постепенно ведёт к цели (боль - решение - призыв в личку);
- при включённом **оркестре** у каждого аккаунта своя роль в спектакле (новичок, эксперт, скептик, клиент).

**Задача НЕ умеет:**

- вести одного живого человека до созвона в личке;
- сама писать в личные сообщения;
- дожимать молчунов ("человек ушёл в туман - напиши ему снова");
- отвечать только выбранному лиду - отвечает на **любые** чужие сообщения в чате.

Для личных диалогов с лидами используйте другие задачи (например, **15 Рассыльщик в ЛС**, **16 Автоответчик**).

---

## Куда можно писать (важно!)

| Тип | Можно? | Почему |
|-----|--------|--------|
| **Группа / супергруппа** | Да | Обычные участники могут писать, если не закрыты права |
| **Обсуждения под постом канала** | Да | Это отдельная группа, ссылка вида `@channelname` или ссылка на чат обсуждений |
| **Канал без обсуждений** | **Нет** | В канал пишут только админы. Ошибка: `You can't write in this chat` |

**Перед запуском:**

1. Все аккаунты из `Аккаунты/` **добавлены в чат** (подписка, инвайт или вручную).
2. У аккаунтов есть право **отправлять сообщения** (не только читать).
3. В **Таблица аккаунтов** (задача 22) аккаунты **свободны** (нет статуса "занят"). Если зависли - кнопка **`Освободить`**.

## Список чатов (таблица `23 0 ИИ диалог чаты`)

Чаты задаются не в настройках, а в таблице - по одной ссылке в строку. Как открыть таблицу - [глава 2](02_Подготовка_данных.md).

| Колонка | Кто заполняет | Что там |
|---------|---------------|---------|
| `✅ №` | Программа | Номер строки |
| `✅ Ссылка на чат` | Вы | `@mygroup` или ссылка t.me/... |
| `Задача` | Программа | Отметка после обработки |

Отметки в колонке `Задача`:

| Отметка | Что значит |
|---------|-----------|
| пусто | Чат ещё не обработан, попадёт в ближайший запуск |
| `🟡` | Чат в работе прямо сейчас |
| `✅ Отработан` | Аккаунты отыграли в чате весь сценарий |
| `❌ Нет доступа` | Ни одна реплика не ушла: нет доступа, бан или это канал |

**Как идёт обход:** аккаунты приходят в первый необработанный чат, отыгрывают там весь сценарий (при включённой дуге - все её фазы), затем задача выдерживает **Задержка между чатами (сек)** и переходит к следующему чату. Прогресс дуги хранится отдельно для каждого чата, поэтому чаты не мешают друг другу.

Когда весь список отработан, следующий запуск **сбрасывает отметки** и начинает новый круг.

## Пошаговый запуск

1. Запустите AlexSoftClub двойным щелчком по `.exe`.
2. В главном меню **мышкой** откройте раздел **AI-ОБЩЕНИЕ** - задача **`23` ИИ диалог аккаунтов**.
3. Впишите чаты в таблицу `23 0 ИИ диалог чаты` - по одной ссылке в строку.
4. Заполните настройки (см. таблицу ниже).
5. Подготовьте папку `Data/AI/` (см. [главу 14](14_Промпты_для_ИИ.md)).
6. Нажмите **`Продолжить`** внизу экрана настроек.
7. Дождитесь завершения. Статус смотрите в логе (см. [главу 10](10_Структура_проекта_прокси_логи.md)).
8. Результат - в таблице `23 1 ИИ диалог отчеты` в `База данных.db`.

Чтобы выйти без запуска - кнопка **`Назад`**.

## Все настройки задачи 23

| Настройка | Что значит | Рекомендация для старта |
|-----------|------------|-------------------------|
| **Кол-во чатов за запуск** | Сколько чатов из списка `23 0 ИИ диалог чаты` взять за один запуск | "Без ограничений" - весь список |
| **Задержка между чатами (сек)** | Пауза после отработки чата, перед переходом к следующему | `60-180`, для больших списков больше |
| **Тема диалога** | Общая рамка разговора для всех аккаунтов | Одна фраза: "Обсуждаем, стоит ли записаться на созвон" |
| **URL API агрегатора** | Адрес LLM без `/chat/completions` | См. [главу 13](13_Настройка_LLM_API.md) |
| **LLM API ключ** | Ключ сервиса | Обязательно |
| **LLM модель** | Id модели | `gpt-4o-mini`, `gpt-4o` и т.п. |
| **Кол-во сообщений на аккаунт** | Сколько **реплик** отправит **один** аккаунт за **один прогон** | `1-2` для теста, `2-4` для живого чата |
| **Задержка после сообщения (сек)** | Пауза **между своими** репликами одного аккаунта | `30-90` (в секундах, не минутах!) |
| **Включить дугу** | Пошаговый сценарий intro - pain - offer - cta | `Да` если нужен призыв в личку |
| **Включить оркестр** | Разные роли аккаунтов (новичок, эксперт...) | `Да` если аккаунтов 3+ |
| **Отвечать только своим аккаунтам** | Reply только коллегам из запуска; живые пишутся в журнал, но reply на них нет | `Да` для "спектакля" в чате с посторонними |
| **Отвечать живым участникам** | Reply на посторонних из журнала чата | `Да` если нужно вести живых людей |
| **Приоритет ответа (1/2/3)** | `1` - сначала живые, `2` - сначала свои, `3` - любой неотвеченный | `2` по умолчанию |
| **Кол-во одновременно работающих потоков** | Сколько аккаунтов работают **параллельно** | `1-3` для теста |
| **Задержка перед выполнением следующего потока/группы потоков (сек)** | Пауза между фазами дуги и волнами аккаунтов | `15-120` |

## Потоки, фазы и сообщения - простыми словами

### Потоки = сколько аккаунтов одновременно

`Кол-во одновременно работающих потоков: 2` - в один момент пишут **2 аккаунта**. Остальные ждут очереди.

### Фазы дуги вместо "циклов"

При **Включить дугу: Да** отдельная настройка "Кол-во циклов" **не используется**. Один запуск задачи проходит **все фазы** из `Data/AI/arc.txt` (обычно 4: intro, pain, offer, cta). Между фазами - пауза из "Задержка перед выполнением следующего потока".

Чтобы растянуть сценарий на неделю - **запускайте задачу снова** через день: фаза каждого аккаунта хранится в `23 2 ИИ диалог дуга`.

Без дуги - один прогон на запуск (как раньше "1 цикл").

### Сообщений на аккаунт = реплик за одну фазу

`Кол-во сообщений на аккаунт: 1-3` - каждый аккаунт за один прогон отправит от 1 до 3 сообщений (случайно).

Одно сообщение = **одна реплика** в чат (не пара "вопрос+ответ"). Ответ на чужое сообщение - это тоже одна реплика.

### Задержка после сообщения - в секундах

`Задержка после сообщения (сек): 60-120` - между **своими** репликами один аккаунт ждёт 60-120 секунд.

Для "живого" чата ставьте **разброс**: например, от 45 до 180 секунд.

## Дуга и оркестр

### Дуга (`Включить дугу: Да`)

Файл `Data/AI/arc.txt` задаёт фазы разговора. По умолчанию:

| Фаза | Задача аккаунта |
|------|-----------------|
| **intro** | Войти в тему как обычный участник |
| **pain** | Упомянуть проблему без названия продукта |
| **offer** | Органично назвать решение |
| **cta** | Мягко предложить написать в личку |

Текущая фаза каждого аккаунта хранится в таблице `23 2 ИИ диалог дуга`. После каждого прогона фаза сдвигается на следующую.

Чтобы "сбросить" сценарий - удалите строки из `23 2 ИИ диалог дуга` для нужного чата.

### Оркестр (`Включить оркестр: Да`)

Файл `Data/AI/orchestra.txt` задаёт роли по слотам:

- слот 0 - новичок (задаёт вопросы);
- слот 1 - эксперт (отвечает авторитетно);
- слот 2 - скептик (сомневается, потом соглашается);
- слот 3 - довольный клиент (личный кейс).

Слот закреплён за аккаунтом на весь прогон (по порядку ID в списке задачи): слот 0, 1, 2, 3.

При включённой дуге в каждой фазе пишет только один слот: intro=0, pain=1, offer=2, cta=3. Остальные аккаунты в этом цикле молчат.

Роли из папки `Data/AI/roles/` при оркестре назначаются **по слоту**, а не случайно.

## Полный пример: PumpKing Bundler - зовём в ЛС без ссылок в чате

**Задача:** в крипто-группе разыграть живой диалог про запуски мемкоинов. В чате **нельзя** кидать ссылки и `@PumpKingBundlerBot`. Люди сами пишут вам в личку и просят бота - вы отвечаете вручную.

**Что нужно:**

- Группа (не канал!), например `@crypto_launches_chat`
- **4 аккаунта** в группе, все **освобождены** в задаче 22
- `Включить дугу: Да`, `Включить оркестр: Да`

---

### Настройки задачи 23

| Параметр | Значение | Зачем |
|----------|----------|-------|
| **Чаты (таблица `23 0 ИИ диалог чаты`)** | `@crypto_launches_chat` | Ваши целевые группы, по одной в строку |
| **Тема диалога** | `Обсуждаем запуски на pump и как не словить снайперов` | Рамка всего разговора |
| **Кол-во сообщений на аккаунт** | `1-2` | Не спамим стеной текста |
| **Задержка после сообщения (сек)** | `90-240` | Живые паузы между репликами |
| **Включить дугу** | `Да` | intro - pain - offer - cta |
| **Включить оркестр** | `Да` | 4 разных персонажа |
| **Потоки** | `2` | Два аккаунта параллельно |
| **Циклы** | `4` | Ровно 4 фазы дуги за один "сезон" |
| **Задержка перед следующим потоком (сек)** | `120` | Пауза между волнами |

После 4 циклов все аккаунты дойдут до фазы **cta** и начнут звать в личку. Для растягивания на неделю: `Циклы: 4`, но запускайте задачу **раз в 1-2 дня** (фазы сохраняются в `23 2 ИИ диалог дуга`).

```
Ты обычный участник крипто-чата в Telegram. Не бот, не менеджер, не рекламщик.

Жёсткие правила:

- Максимум 2 коротких предложения. Не больше 250 символов.
- Тон: как в крипто-чате - живой, без канцелярита, можно сленг (sniper, bundle, launch).

- Не говори что ты ИИ.
- Не повторяй одну и ту же фразу.
- Факты только из базы знаний и контекста чата - не выдумывай цифры.
- Если кто-то в чате спрашивает ссылку - отвечай: "в чате нельзя кидать ссылки, напиши в лс".
```

### `Data/AI/arc.txt`

```
=== intro ===
Ты в начале разговора. Войди в тему запусков мемкоинов, снайперов, бандлов - как обычный участник чата. Без рекламы, без упоминания ботов и ссылок. Можно задать вопрос или поделиться наблюдением.

=== pain ===
Упомяни боль: снайперы съедают вход, руками не успеваешь, потерял на запуске, бандл не собрался вовремя. Не называй продукт и бота - только личный опыт или наблюдение из чата.

=== offer ===
Скажи что нашёл рабочий инструмент / бота / способ, который решает эту проблему. Можно сказать "пользуюсь одним ботом для бандла" - но БЕЗ названия, БЕЗ @ и БЕЗ ссылок. 1-2 предложения, без навязчивости.

=== cta ===
Мягко предложи написать в личку тем, кому интересно. Обязательно намекни что в чате нельзя кидать ссылки. Примеры формулировок: "напиши в лс - скину", "в чате ссылки банят, пиши в личку - дам доступ". Без давления.
```

### `Data/AI/knowledge/pumpking_bundler.txt`

```
Тема: Бандлеры для запусков мемкоинов (pump.fun и аналоги).

Факты (для диалога в чате - БЕЗ названия бота):
1) Снайпер-боты покупают в первые секунды после launch - ручной вход часто опаздывает.
2) Бандл = покупка с нескольких кошельков одновременно в момент запуска - создаёт объём и позволяет войти раньше толпы.
3) Главная боль: не успел, снайперы забрали ликвидность, вошёл на хаях и вылетел в минус.
4) Автоматизация через бота экономит секунды - на launch секунды решают.
5) Риски: любой launch может быть rug, бот не гарантирует профит - только скорость входа.
6) В публичных чатах часто запрещены ссылки на ботов - поэтому доступ дают в личке.

Что говорить в чате:
- "есть бот для бандла, сам пользуюсь"
- "на последнем запуске успел собрать бандл до снайперов"
- "в чате ссылки нельзя - напиши в лс"

Что говорить ТОЛЬКО в личке (не для чата):
- Бот: @PumpKingBundlerBot
- Ссылка: t.me/PumpKingBundlerBot
```

### Как выглядит диалог по циклам (пример реплик)

**Цикл 1 - фаза intro** (все аккаунты на intro):

| Кто (слот) | Пример реплики в чате |
|------------|----------------------|
| Новичок | кто вообще успевает на эти запуски? вчера опять все разобрали за секунду |
| Деген | да там снайперы сидят, руками без шансов |
| Скептик | или просто руки кривые, не всем нужны боты |
| Юзер | я вот в прошлый раз вообще в последний момент кликнул - еле ноги унёс |

**Цикл 2 - фаза pain:**

| Кто | Пример реплики |
|-----|----------------|
| Новичок | а что такое бандл вообще? это когда с нескольких кошельков заходишь? |
| Деген | да, иначе один кошелёк не успевает - снайперы первые блоки забирают |
| Скептик | на практике все равно в минус выходят, видел кучу запусков |
| Юзер | я на позапрошлом launch влетел на хаях, снайперы уже вышли к тому моменту |

**Цикл 3 - фаза offer:**

| Кто | Пример реплики |
|-----|----------------|
| Новичок | и как тогда нормальные люди успевают? |
| Деген | я через одного бота бандл собираю, реально быстрее чем руками |
| Скептик | очередной бот, который на деле не работает? |
| Юзер | у меня сработало - на прошлом запуске вошёл раньше основной толпы |

**Цикл 4 - фаза cta** (здесь зовём в ЛС):

| Кто | Пример реплики |
|-----|----------------|
| Деген | в чате ссылки банят, напиши в лс - расскажу что юзаю |
| Юзер | да, мне тоже в личку писали когда спрашивали - так проще |
| Скептик | ну ок, если реально работает - напишу в лс |
| Новичок | о, а мне тоже можно? куда писать - в лс кому? |

Живые люди в чате видят обсуждение и сами пишут вам в личку. Софт **не отправляет** ссылку на бота - это делаете **вы вручную**.

---

### Что делать в личке (ваша часть, вручную)

Когда человек пишет в ЛС после диалога:

1. Ответьте естественно, не шаблоном с первой секунды.
2. Спросите что именно интересует (бандл, скорость, pump).
3. Дайте ссылку:

```
Вот бот: @PumpKingBundlerBot
или t.me/PumpKingBundlerBot
```

4. Коротко объясните: бандл на launch, обход снайперов, риски остаются.
5. Не обещайте гарантированный профит.

**Автоответчик (задача 16)** можно подключить позже, если поток лидов в ЛС вырастет. Задача 23 только **подводит** к личке через чат.

---

### Чек-лист именно для этого кейса

- [ ] В `system_prompt.txt` и `arc.txt` прописан запрет ссылок и @ в чате
- [ ] В `knowledge/` есть блок "что говорить ТОЛЬКО в личке" с `@PumpKingBundlerBot`
- [ ] 4 аккаунта в группе, `Включить оркестр: Да`
- [ ] `Циклы: 4` - чтобы за один "сезон" дойти до cta
- [ ] Тест: 1 цикл, 1 аккаунт - убедиться что в чате **нет** ссылок и @
- [ ] Вы готовы отвечать в ЛС вручную

## Как аккаунты отвечают в чате

1. Аккаунт читает последние сообщения чата.
2. С вероятностью ~70% отвечает **reply** на чужое сообщение (не своё).
3. С вероятностью ~30% пишет **новую** реплику без reply.
4. Нейросеть получает: system_prompt + роль + дуга/оркестр + knowledge + тема + контекст чата.
5. В чат уходит **одна короткая фраза** (1-2 предложения по промпту).

**Журнал чата:** все сообщения (свои и чужие) пишутся в таблицу **`23 3 ИИ диалог сообщения чата`**. Перед каждой репликой софт обновляет журнал из Telegram, контекст и reply берёт из БД.

**На комментарии других участников:**
- `Отвечать только своим: Да` - reply только коллегам, живые только в журнале и в контексте LLM
- `Отвечать живым: Да` + приоритет `1` - сначала reply на последнее **неотвеченное** сообщение живого
- После reply поле `отвечено` в `23 3` = 1, повторно на то же сообщение не отвечают

**Перевод в личку:** только текстом в реплике (фаза **cta**). Автоматически в ЛС софт не пишет.

## Где смотреть результат

### Таблица `23 1 ИИ диалог отчеты`

| Колонка | Что там |
|---------|---------|
| `run_id` | Номер запуска (одинаковый у всех реплик одного прогона) |
| `account_id` | ID аккаунта, который писал |
| `чат` | Ссылка на чат из таблицы `23 0 ИИ диалог чаты` |
| `ссылка на сообщение` | Прямая ссылка на реплику в Telegram (если отправка успешна) |
| `сообщение` | Текст реплики |
| `время сообщения` | Когда отправлено |

**Важно:** в отчёт попадают только реплики, которые **реально ушли** в чат. Если отправка упала - записи не будет (смотрите лог).

### Таблица `23 2 ИИ диалог дуга`

Текущая фаза дуги для пары "аккаунт + чат". Заполняется софтом, вручную обычно не трогают (кроме сброса).

### Таблица `23 3 ИИ диалог сообщения чата`

Журнал всех реплик в чате (свои и чужие). Заполняется софтом при каждом запуске задачи 23.

| Колонка | Что там |
|---------|---------|
| `message_id` | ID сообщения в Telegram |
| `чат` | Ссылка на чат |
| `sender_id` | Кто написал |
| `свой` | `1` - аккаунт из текущего запуска, `0` - посторонний |
| `reply_to_id` | На какое сообщение был reply |
| `текст` | Текст реплики |
| `отвечено` | `1` - наш аккаунт уже ответил reply на это сообщение |
| `источник` | `scan` (прочитано из чата) или `sent` (отправлено нами) |

## Частые проблемы

| Симптом | Причина | Что делать |
|---------|---------|------------|
| `Пустой список: 23 0 ИИ диалог чаты` | Таблица чатов пустая | Впишите ссылки в `23 0 ИИ диалог чаты`, по одной в строку |
| Чат помечен `❌ Нет доступа` | Ни одна реплика не ушла | Проверьте лог: канал вместо группы, бан аккаунтов или нет права писать |
| Задача взяла не все чаты | Сработала настройка **Кол-во чатов за запуск** | Поставьте "Без ограничений" или увеличьте число |
| В базе есть текст, в чате пусто | Писали в **канал**, не в группу | Укажите группу или чат обсуждений; проверьте лог: `You can't write in this chat` |
| Нет ссылки на сообщение в отчёте | Отправка не удалась | См. лог; исправьте права аккаунта в чате |
| `нет свободных аккаунтов` | Все заняты после прошлого запуска | Задача 22 - **`Освободить`** |
| Однотипные длинные ответы | Модель игнорирует промпт | Ужесточите `system_prompt.txt`: "максимум 2 предложения, до 200 символов" |
| Бот отвечает всем подряд | Так устроена логика | Для лидов в ЛС - другая задача |
| Правки в `Data/AI` не видны | Файлы читаются при работе потока | Перезапустите задачу 23 |
| Ошибка LLM / пустой ответ | Ключ, модель, баланс | [Глава 13](13_Настройка_LLM_API.md) |

## Чек-лист перед боевым запуском

- [ ] Чаты вписаны в `23 0 ИИ диалог чаты`, каждый - **группа** или обсуждения, не канал
- [ ] Все аккаунты **в чате** и могут писать
- [ ] Аккаунты **освобождены** в таблице аккаунтов
- [ ] LLM API заполнен и проверен
- [ ] `Data/AI/system_prompt.txt`, `roles/`, `knowledge/` готовы
- [ ] При нужном сценарии: `Включить дугу` = `Да`, `arc.txt` отредактирован
- [ ] При 3+ аккаунтах: `Включить оркестр` = `Да`
- [ ] Задержки в **секундах**, с разбросом (не `1-1`), включая **Задержка между чатами (сек)**
- [ ] Тестовый прогон: 1 аккаунт, 1 цикл, 1 сообщение - проверить чат и отчёт
