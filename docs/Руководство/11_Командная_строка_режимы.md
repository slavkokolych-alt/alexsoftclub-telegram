# 11. Управление программой

Программа управляется **мышкой** через визуальное меню. Все настройки задаются прямо в интерфейсе перед запуском - открывать файлы вручную не нужно.

---

## Основы управления

- **Мышкой** - кликайте по пунктам меню и кнопкам.
- **"Назад"** - вернуться на предыдущий экран.
- **"Отмена"** - отменить запуск или действие.
- **`Ctrl + C`** - экстренно закрыть программу (только если что-то пошло не так).

<div class="box box-info">
ℹ️ Программа <b>запоминает</b> все настройки каждой задачи (задержки, потоки, методы) и подставит их при следующем запуске. Ничего перенастраивать заново не нужно.
</div>

---

## Задержка перед стартом

После кнопки **"Продолжить"** программа предложит ввести задержку в секундах:

- Введите число (например, `30`) и нажмите **"Запустить"** - пойдёт обратный отсчёт.
- Нажмите **"Запустить"** без числа - старт сразу.
- **"Отмена"** - передумали.

---

## Остановка бесконечных задач

Некоторые задачи работают, пока вы их не остановите (например, **Клонер каналов** в режиме мониторинга или **Лайкер** в режиме мониторинга).

Чтобы завершить безопасно - введите **`0`** и нажмите ENTER в окне программы. Она доделает текущее действие и корректно отключится.

---

## Запуск без меню (для продвинутых)

<div class="box box-info">
Этот раздел можно <b>смело пропустить</b>, если вы работаете через обычное меню. Он нужен только для автоматического запуска на сервере без участия человека.
</div>

Для запуска по расписанию есть команды:

| Команда | Пример | Что делает |
|---------|--------|-----------|
| `--task <N>` | `AlexSoftClub.exe --task 17` | Запускает задачу, минуя меню. |
| `--subtask <N>` | `AlexSoftClub.exe --task 15 --subtask 1` | Выбирает подзадачу (для задач 1, 14, 15, 17). |
| `--auto` | `AlexSoftClub.exe --task 9 --auto` | Запуск с ранее заданными настройками. |
| `--quiet` | `AlexSoftClub.exe --task 4 --quiet` | Без подробного вывода на экран (для слабых серверов). |
| `--account-id <ID>` | `AlexSoftClub.exe --task 4 --account-id 12345` | Только один конкретный аккаунт. |
