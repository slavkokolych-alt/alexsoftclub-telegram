# 14. Промпты и задания для нейросети

Как задать текст для **нейрокомментинга (задача 19)** и **ИИ-диалога (задача 23)**.

Настройки LLM API (URL, ключ, модель) - в [главе 13](13_Настройка_LLM_API.md).

---

## Две разные схемы

| Задача | Где задаётся "промпт" | Когда нужен LLM |
|--------|------------------------|-----------------|
| **19 Комментинг/НейроКомментинг** | Таблица `19 4 Комментинг комментарии` в базе | Строка начинается с `GPT:` |
| **23 ИИ диалог аккаунтов** | Папка `Data/AI/` рядом с программой | Всегда (каждое сообщение) |

## Задача 19: нейрокомментинг

### Какие таблицы заполнить

Откройте **База данных.db** в SQLiteStudio (см. [главу 2](02_Подготовка_данных.md)).

| Таблица | Зачем |
|---------|--------|
| `19 1 Комментинг ключевые слова в постах` | Комментировать только посты, где есть эти слова (пустая таблица = без фильтра) |
| `19 2 Комментинг cтоп слова в постах` | Не трогать посты со стоп-словами |
| `19 3 Комментинг cтоп слова в комментариях` | Не публиковать, если нейросеть вернула стоп-слово |
| **`19 4 Комментинг комментарии`** | **Шаблоны комментариев и GPT-задания (главное)** |
| `19 5 Комментинг отредактированные комментарии` | Тексты для режима "Редактировать комментарии" (см. настройку задачи 19) |
| `19 6 Комментинг результаты` | Заполняется софтом - история комментариев |

Аккаунт комментирует **новые посты в каналах, на которые он подписан** (отдельную таблицу ссылок для задачи 19 нет).

### Формат строки в `19 4 Комментинг комментарии`

**Вариант 1 - фиксированный комментарий (без нейросети)**

В ячейку пишете готовый текст. Софт может подставить случайный вариант из `{вариант1|вариант2}`.

Примеры:

```
Отличный разбор, спасибо!
{Согласен|Полезно|Интересно}, возьму на заметку
```

**Вариант 2 - нейрокомментинг (с нейросетью)**

Строка **обязательно** начинается с `GPT:` (латиница, можно `GPT：` с двоеточием).

После двоеточия - ваше задание. К тексту поста в канале софт **сам добавит** содержимое поста в конец запроса.

Пример ячейки:

```
GPT: Прочитай пост и напиши короткий возмущённый комментарий по теме. Упомяни, что в моём канале @mychannel разбор другой. Без хештегов, 1-2 предложения.
```

Софт отправит в LLM примерно так: `ваше задание: текст поста`.

**Несколько заданий:** добавьте несколько строк в таблицу - для каждого нового поста выбирается **случайная** строка из списка.

### Дополнительные метки в шаблоне (задача 19)

| Метка | Назначение |
|-------|------------|
| `HIDE_URL` | Убрать превью ссылок в комментарии |
| `https://t.me/addstickers/ИмяНабора` | Сначала отправить стикер из набора, затем (при GPT) - сгенерированный текст |
| `{слово1\|слово2}` | Случайная подстановка перед отправкой |

### Режим "Редактировать комментарии"

Если в настройках задачи **19** включено `Редактировать комментарии (1 - Да / 2 - Нет)` = **1**:

1. Сначала в обсуждение уходит короткий комментарий (эмодзи из встроенного списка).
2. Через паузу из настроек текст **меняется** на строку из таблицы `19 5 Комментинг отредактированные комментарии`.

В `19 5` тоже можно использовать `GPT:` - тогда финальный текст после редактирования генерирует нейросеть.

### Пример готового набора для крипто-ниши

Таблица `19 4`:

```
GPT: Напиши короткий комментарий по теме поста, тон - опытный трейдер. Без воды, 1-2 предложения, на языке поста.
GPT: Слегка поспорь с автором поста, аргументируй фактом из текста. Вежливо, без токсичности.
👍
```

Таблица `19 5` (если редактирование включено):

```
GPT: Перепиши в развёрнутый комментарий с призывом заглянуть в @mychannel. 2 предложения.
```

## Задача 23: ИИ диалог аккаунтов

### Где лежат файлы (папка `Data/AI`)

Папка создаётся **рядом с программой** (там же, где `AlexSoftClub.exe`), не внутри SQLite.

```
Data/AI/
├── README.txt
├── system_prompt.txt       <- общие правила для ВСЕХ аккаунтов
├── arc.txt                 <- фазы дуги (intro, pain, offer, cta) - если "Включить дугу: Да"
├── orchestra.txt           <- роли по слотам (новичок, эксперт...) - если "Включить оркестр: Да"
├── roles/                  <- "характер" каждого участника чата
│   ├── znatok.txt
│   └── somnevayushchiysya.txt
└── knowledge/              <- "база фактов" по вашей теме (текстовые файлы)
    └── crypto_example.txt
```

Пошаговый запуск, настройки потоков/циклов и тип чата (группа vs канал) - в [главе 15](15_ИИ_диалог_аккаунтов.md).

При первом запуске софт может создать примеры. **Ваши правки не затираются** при следующих запусках.

**Важно:** папка `knowledge/` - это не файл `База данных.db`. Это обычные `.txt`, которые вы редактируете в Блокноте. Таблицы SQLite для задачи 23 не нужны - только настройки задачи и эта папка.

---

### Простыми словами: три слоя

Представьте, что нейросеть - актёр в чате. Вы даёте ему три инструкции:

| Слой | Файл | Простая аналогия |
|------|------|------------------|
| 1 | `system_prompt.txt` | Правила съёмочной площадки: язык, длина сообщений, что нельзя |
| 2 | `roles/имя.txt` | Роль в спектакле: эксперт, скептик, новичок |
| 3 | `knowledge/*.txt` | Шпаргалка с фактами о продукте/нише, чтобы не врать |

Плюс в **настройках задачи 23** поле **`Тема диалога`** - одна фраза, о чём вообще разговор ("аренда квартир", "крипта 2026", "наш SaaS").

---

### 1. `system_prompt.txt` - что писать

**Это общие правила для всех аккаунтов.** Пишите короткими пунктами, как ТЗ для живого человека.

**Что обычно указывают:**

- На каком языке писать (часто: "как в чате - русский/английский").
- Длина: "1-2 предложения", "без простыней".
- Тон: дружелюбный, деловой, сленг ниши.
- Запреты: не говорить что ты бот/ИИ; не оскорблять; не повторять одну и ту же фразу.
- Откуда брать факты: "только из базы знаний и переписки в чате, не выдумывай цифры".

**Пример (можно скопировать и подправить под себя):**

```
Ты обычный участник Telegram-чата, не бот и не менеджер поддержки.

Правила:
- Пиши на том же языке, что и остальные в чате.
- Сообщения короткие: 1-2 предложения, без списков из 10 пунктов.
- Тон: спокойный, по делу, без паники и без токсичности.
- Не пиши "как ИИ", "я языковая модель", не используй канцелярит.
- Не повторяй одну и ту же формулировку в каждом сообщении.
- Если не уверен в факте - задай вопрос, не придумывай.
- Опирайся на факты из базы знаний (файлы knowledge) и на то, что уже писали в чате.
```

**Не нужно:** длинные истории, код, ссылки на API. **Нужно:** чёткие "делай / не делай".

---

### 2. `roles/` - что писать в каждый файл

**Один файл = один тип личности.** Имя файла любое латиницей или кириллицей: `expert.txt`, `novichok.txt`, `skeptik.txt`.

Софт при старте аккаунта **случайно** выбирает один файл из папки. Если файл один - все пишут одинаково.

**Что писать внутри файла:**

- Кто ты по роли (1 строка): "Опытный риелтор", "Новичок в крипте".
- Как ведёшь себя: задаёшь вопросы / споришь / соглашаешься / шутишь.
- Чего избегаешь: "не читай лекции", "не будь агрессивным".

**Пример - эксперт (`roles/expert.txt`):**

```
Роль: Опытный специалист по теме.

Поведение:
- Отвечай уверенно, с примером из жизни или практики.
- Если видишь ошибку в чужом сообщении - мягко поправь, без снобизма.
- Не пиши больше двух предложений за раз.
```

**Пример - скептик (`roles/skeptik.txt`):**

```
Роль: Осторожный участник, который всё перепроверяет.

Поведение:
- Часто спрашивай "а откуда цифры", "а что если наоборот".
- Не соглашайся сразу - проси аргументы.
- Тон вежливый, без хамства.
```

**Пример - новичок (`roles/novichok.txt`):**

```
Роль: Человек, который только разбирается в теме.

Поведение:
- Задавай простые вопросы "а это безопасно", "с чего начать".
- Иногда признавай, что не до конца понял.
- Не притворяйся экспертом.
```

**Совет:** сделайте 2-4 роли с разным характером - переписка в чате выглядит живее.

---

### 3. `knowledge/` - база фактов (что писать)

**Это ваша "шпаргалка" для нейросети.** Все файлы `.txt` из папки `knowledge/` софт **склеивает** и подставляет в каждый запрос как блок "Контекст знаний".

Пишите так, как для стажёра: короткие тезисы, без воды.

**Что сюда класть:**

- Факты о продукте/услуге: цена, сроки, для кого, чем отличается от конкурентов.
- Ответы на частые вопросы: "можно ли в России", "нужен ли депозит", "есть ли риски".
- Цифры и условия, которые **нельзя выдумывать** (если цифры меняются - обновите файл).
- Тезисы для спора в чате: за и против, мифы и правда.

**Чего не класть:**

- Длинные статьи на 5 страниц (нейросеть режет контекст, путаница).
- Промпты и роли (для этого есть `system_prompt` и `roles`).
- Секретные пароли и ключи API.

**Пример файла `knowledge/moj_produkt.txt`:**

```
Тема: Онлайн-курс по Telegram-маркетингу.

Факты:
- Курс 4 недели, формат: видео + чат поддержки.
- Цена: 9900 руб, рассрочка нет.
- Подходит новичкам с 0 подписчиков.
- Не обещаем "миллион за неделю" - учим системе, а не "хайпу".
- Есть домашние задания, без них смысла мало.

Частые вопросы:
- Нужен ли Premium? Нет, для курса не обязателен.
- Сколько аккаунтов? Рекомендуем 1-3 на старте.
```

Можно несколько файлов: `knowledge/ceny.txt`, `knowledge/riski.txt` - все подтянутся вместе.

**Если база пустая:** аккаунты будут говорить "общими фразами" и могут выдумывать детали. Для продажи/экспертизы **базу лучше заполнить**.

---

### 4. Поле `Тема диалога` в настройках задачи 23

Откройте задачу **23** в программе, в списке настроек найдите **`Тема диалога`**.

Одна короткая фраза, которая задаёт рамку всему чату:

- `Обсуждаем, стоит ли брать крипту на просадке`
- `Чат про аренду квартир в Москве`
- `Отзывы о нашем курсе`

Если оставить пустым - софт подставит нейтральное "Обсуждение без темы".

---

### Как это собирается перед отправкой в нейросеть

Каждое новое сообщение аккаунта:

1. Берётся текст из `system_prompt.txt`.
2. Добавляется случайная роль из `roles/`.
3. Добавляется всё из `knowledge/*.txt`.
4. Добавляется **Тема** из настроек.
5. Добавляются последние реплики из реального чата (чтобы ответ был в контексте).
6. Нейросеть возвращает **одну короткую фразу** - её аккаунт отправляет в Telegram.

Вы **не видите** этот большой текст в чате - видите только готовое сообщение.

---

### Пошагово для новичка (задача 23)

1. Запустите программу один раз - появится папка `Data/AI/`.
2. Откройте `system_prompt.txt` в Блокноте - впишите правила (см. пример выше).
3. В `roles/` оставьте 2-3 файла с разным характером или один - если нужен один стиль.
4. В `knowledge/` создайте файл с фактами по вашей нише (5-15 тезисов достаточно для старта).
5. Впишите чаты в таблицу `23 0 ИИ диалог чаты`, в настройках задачи 23 укажите **Тема диалога** и **LLM API** (глава 13).
6. Запустите задачу, кнопка **`Продолжить`**.

---

### Одна роль или несколько

| Цель | Что сделать |
|------|-------------|
| Все аккаунты говорят одинаково | В `roles/` только **один** `.txt` |
| В чате "разные люди" спорят | В `roles/` **2-4** разных файла, `Включить оркестр: Да` |

---

### 5. `arc.txt` - дуга разговора

Включается настройкой **`Включить дугу: Да`**. Файл разбит на секции `=== название ===`:

```
=== intro ===
Текст задачи для первой фазы...

=== pain ===
Текст для фазы "боль"...

=== offer ===
...

=== cta ===
Мягко предложи написать в личку...
```

Софт по очереди подставляет фазу каждому аккаунту. Прогресс хранится в таблице `23 2 ИИ диалог дуга`.

### 6. `orchestra.txt` - роли в спектакле

Включается настройкой **`Включить оркестр: Да`**. Секции `=== слот 0 ===`, `=== слот 1 ===` и т.д. - кто как ведёт себя в чате (новичок, эксперт, скептик, клиент).

Первый аккаунт в запуске - слот 0, второй - слот 1. Подробнее - [глава 15](15_ИИ_диалог_аккаунтов.md).

---

### Напоминание: "база данных" для нейрокомментинга (задача 19)

Если вы имели в виду **таблицы в `База данных.db`** (SQLiteStudio) - это **другая** задача:

- Там шаблоны с **`GPT:`** в таблице **`19 4 Комментинг комментарии`**.
- Папка `Data/AI/` для задачи 19 **не используется**.

Подробнее - раздел "Задача 19" в начале этой главы.

---

## Частые ошибки

| Проблема | Решение |
|----------|---------|
| Нейрокомментинг пишет шаблон `GPT:...` в чат | В `19 4` нет префикса `GPT:` или опечатка - должно быть `GPT:` в начале строки |
| ИИ-диалог "пустой" или однотипный | Проверьте LLM в [главе 13](13_Настройка_LLM_API.md); упростите `system_prompt.txt` |
| В базе есть текст, в чате нет | Писали в канал, не в группу - см. [главу 15](15_ИИ_диалог_аккаунтов.md) |
| Правки в `Data/AI` не видны | Перезапустите задачу 23 - файлы читаются при работе потока |
| Софт не создал `Data/AI` | Запустите программу один раз из папки с `.exe` - папка появится рядом с программой |
