# 12. Результаты и решение проблем

Всё, что делают аккаунты, программа пишет в базу данных. После работы можно закрыть программу и спокойно проанализировать результат.

---

## Где смотреть результаты

Откройте `База данных.db` в **SQLiteStudio** и найдите нужную таблицу (например, `10 1 Рассыльщик в чаты ссылки`).

Колонка **`Задача`** (или `Статус`) показывает, что произошло со строкой:

| Значение | Что значит |
|----------|-----------|
| *(пусто)* | Строка свободна - при следующем запуске программа её возьмёт. |
| `0` / `Успешно` / `Отправлено` | Обработано успешно. |
| Набор цифр | Программа прямо сейчас работает с этой строкой. |
| 🟢 / 🟡 / 🔴 | Успех / в работе / ошибка (в подписке и сторис). |
| ⏳ | Отправлена заявка на вступление (ждёт одобрения админа). |
| 🔐 | Канал за сложной проверкой - пройти вручную (см. [главу 5](05_Рассылка.md)). |
| `Таймаут (FloodWait)` | Аккаунт получил временную паузу от Telegram на этой строке. |
| `Запрет (ChatWriteForbidden)` | Нет прав писать в эту группу. |
| `Приватность (PrivacyRestriction)` | Пользователь запретил писать/приглашать себя. |

<div class="box box-tip">
💡 <b>Запустить рассылку по той же базе повторно?</b> Очистите колонку <code>Задача</code> (сделайте ячейки пустыми) и сохраните - база снова готова к работе.
</div>

## Частые ошибки

| Симптом | Причина и решение |
|---------|-------------------|
| **Ошибка записи (база занята)** | `База данных.db` открыта в SQLiteStudio с несохранёнными правками. Сохраните или закройте редактор перед запуском. |
| **Второй экземпляр запущен** | Программа открыта дважды. Закройте все окна и запустите один раз. |
| **`Сессия не найдена`** | Telegram удалённо выбросил аккаунт (кто-то нажал "Завершить сеансы"). Удалите папку аккаунта и загрузите профиль заново. |
| **`avatars не обнаружены`** | Для задачи "Установить аватарку" нет фото. Положите `.jpg`/`.png` в `Аватарки/Аватарки для аккаунтов/`. |
| **Задача запускается и сразу выходит** | Все строки уже обработаны (стоит `0`/статус) или ссылок нет. Очистите колонку `Задача` или добавьте ссылки. |
| **Rose-капча не решается при подписке** | Не настроен ключ нейросети. Заполните LLM API (см. [главу 13](13_Настройка_LLM_API.md)). |
| **ИИ-диалог: нет свободных аккаунтов** | Аккаунты заняты после прошлого запуска. Задача 22 → кнопка **"Освободить"**. |
| **ИИ-диалог: `You can't write in this chat`** | Указан канал вместо группы или нет прав писать. Укажите группу; добавьте аккаунты в чат с правом отправки. |

## Нейро-опции (кратко)

- **Нейрокомментинг (19):** настройте LLM ([глава 13](13_Настройка_LLM_API.md)) и заполните `19 4 Комментинг комментарии` - строки с `GPT:` это задания нейросети, без `GPT:` - готовый текст. Подробно - [глава 14](14_Промпты_для_ИИ.md).
- **ИИ-диалог (23):** промпты лежат в папке `Data/AI/`, отчёт - в таблице `23 1 ИИ диалог отчеты`. Пошагово - [глава 15](15_ИИ_диалог_аккаунтов.md).
