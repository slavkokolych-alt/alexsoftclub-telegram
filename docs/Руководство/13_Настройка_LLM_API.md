# 13. Настройка LLM API (общие для всех задач с ИИ)

Краткая инструкция: как подключить любой сервис с **OpenAI-совместимым API** (один URL, один ключ, одна модель).

**Один раз** настраивается в меню **AI-ОБЩЕНИЕ → `24` Настройки LLM API** и используется во всех задачах:

- **[10] Рассыльщик в чаты** (`GPT:` в сообщениях; без ключа - лицензионный прокси)
- **[12] Цитатор комментов в чатах** (то же)
- **[19] Комментинг/НейроКомментинг**
- **[23] ИИ диалог аккаунтов**
- **[8] Подписка на чаты/каналы** - для авто-решения **Rose-капчи** (пример-картинка при верификации). Нужна модель, которая "видит" картинки (vision), например `gpt-4o`. Подробнее - [глава 5](05_Рассылка.md).

Остальные модули с `GPT:` (тегер, рассыльщик в обсуждения и т.д.) работают через **лицензионный прокси** AlexSoftClub.

> 💡 Один и тот же ключ обслуживает все задачи с ИИ. Настроили один раз - работает везде.

---

## Куда зайти в программе

1. Запустите **AlexSoftClub** двойным щелчком по файлу программы (`.exe` в папке, куда вы распаковали архив).
2. Откроется главное меню со списком задач.
3. **Мышкой** щелкните: раздел **AI-ОБЩЕНИЕ** → **`24` Настройки LLM API**.
4. В списке **мышкой** откройте по очереди три пункта (клик по строке):
   - `URL API агрегатора`
   - `LLM API ключ`
   - `LLM модель`
5. В окне редактирования вставьте значение (удобно кнопкой **`Вставить`** из буфера), затем нажмите **`Сохранить`**.
6. Нажмите **`Назад`** - настройки сохранены для всех копий задач на этом ПК.

Для задачи **23** отдельно впишите чаты в таблицу `23 0 ИИ диалог чаты` - по одной ссылке в строку.

При обновлении софта ключи из старых секций задач автоматически переносятся в общий раздел.

---

## Три поля в настройках


| Поле в программе       | Что вставить                                             |
| ---------------------- | -------------------------------------------------------- |
| **URL API агрегатора** | Адрес API **без** `/chat/completions` (см. таблицу ниже) |
| **LLM API ключ**       | Ключ из личного кабинета выбранного сервиса              |
| **LLM модель**         | Точный id модели из документации сервиса                 |


**Важно:** софт сам допишет путь `/chat/completions`. Можно вставить URL с `/v1` в конце - так и нужно.

**Старые поля:** если у вас еще есть `VseLLM API ключ` и `VseLLM модель` - они тоже читаются, но лучше заполнить новые три поля.

## Пример: OpenRouter за 2 минуты

1. Регистрация на [openrouter.ai](https://openrouter.ai), создание ключа.
2. В настройках задачи **19** или **23**:
  - `URL API агрегатора` = `https://openrouter.ai/api/v1`
  - `LLM API ключ` = ваш ключ OpenRouter
  - `LLM модель` = например `openai/gpt-4o-mini` (список на сайте OpenRouter)
3. Запуск задачи, кнопка `**Продолжить`**.

## Пример: VseLLM (как раньше)

1. Ключ и модель - в личном кабинете [vsellm.ru](https://vsellm.ru/).

  - `LLM API ключ` = ключ VseLLM

## Если не работает


| Симптом                            | Что проверить                                          |
| ---------------------------------- | ------------------------------------------------------ |
| Сразу пишет про ключ или URL       | Заполнены `URL API агрегатора` и `LLM API ключ`        |
| Пустой комментарий / нет ответа ИИ | Неверная `LLM модель` или нет денег на балансе сервиса |
| Ошибка HTTP 401                    | Неверный или просроченный ключ                         |
| Ошибка HTTP 404                    | Неверный id модели для этого URL                       |
| Ошибка HTTP 429                    | Лимит запросов - увеличьте паузы в настройках задачи   |


Текст ошибки смотрите в логе программы (см. [главу 10 - логи](10_Структура_проекта_прокси_логи.md)).
