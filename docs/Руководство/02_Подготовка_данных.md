# 2. Подготовка данных (таблицы)

Вся работа программы крутится вокруг одного файла - **`База данных.db`**. В нём лежат все ваши аккаунты, ссылки, тексты и результаты. Файл создаётся автоматически при первом запуске, рядом с `.exe`.

Чтобы вставлять свои ссылки и тексты, вы открываете нужную таблицу в этом файле и заполняете её - как в Excel.

---

## Чем открывать базу данных

Скачайте бесплатную программу **SQLiteStudio** - она открывает файл `База данных.db` и позволяет редактировать таблицы вручную.

<a class="md-btn" href="https://tgengine.alexsoftclub.biz/SQLiteStudio-3.4.17-windows-x64-installer.exe">⬇ Скачать SQLiteStudio (Windows x64)</a>

1. Скачайте установщик по кнопке выше (или с официального сайта [sqlitestudio.pl](https://sqlitestudio.pl)).
2. Запустите файл `SQLiteStudio-3.4.17-windows-x64-installer.exe` и пройдите установку (все настройки по умолчанию).
3. Откройте SQLiteStudio, в меню выберите **"База данных" - "Добавить базу данных"** и укажите файл `База данных.db` из папки с программой.
4. Слева появится база - раскройте её, откройте раздел **"Таблицы"** и двойным щелчком нужную таблицу, вкладка **"Данные"**.
5. После правок нажмите **"Сохранить"** (зелёная галочка) - иначе изменения не попадут в базу.

Таблицу аккаунтов можно посмотреть и внутри самой программы - пункт **22 Таблица аккаунтов**.

<div class="box box-danger">
<b>⚠ Золотое правило.</b> Не держите <code>База данных.db</code> открытым в SQLiteStudio во время работы задачи. Перед запуском задачи <b>сохраните изменения и закройте</b> редактор (или хотя бы нажмите "Сохранить"). Иначе программа не сможет записать результат и выдаст "ошибку записи".
</div>

## Таблица аккаунтов (`01 1 Менеджер аккаунтов`)

Все загруженные аккаунты появляются здесь автоматически. Значок ✅ = колонку можно редактировать вручную:

- **✅ №** - приоритет: аккаунты с меньшим номером берутся в работу первыми.
- **ID аккаунта, Телефон** - заполняет программа.
- **✅ Юзернейм, ✅ Имя, ✅ Фамилия, ✅ О себе** - данные профиля.
- **✅ IP прокси, ✅ Порт прокси, ✅ Логин прокси, ✅ Пароль прокси** - прокси в 4 отдельные колонки. Протокол - SOCKS5.
- **✅ Статус аккаунта** - пусто = свободен; иначе "занят" или текст ошибки/спам-блока.
- **✅ Заметка** - ваши пометки: "в отлёжке", "спам-блок", "резерв".

<div class="box box-tip">
💡 <b>Аккаунт "завис" в статусе "Занят"</b> после аварийного закрытия? Очистите ячейку в колонке <code>Статус аккаунта</code> (сотрите текст, сохраните) - или нажмите <b>"Освободить"</b> в задаче 22.
</div>

## Один пароль 2FA на все аккаунты

Если у аккаунтов включена облачная двухэтапная аутентификация (2FA), можно задать **один общий пароль** для программы:

- Задача **1 Менеджер аккаунтов → Установить 2FA**: введите/смените пароль - программа подключится к аккаунтам и включит 2FA прямо в Telegram.
- Пароль сохранится в настройках и будет подставляться автоматически.

## Форматы ссылок

Для парсинга, рассылки и подписки программа ждёт ссылки Telegram. Копируйте их **из приложения** (правой кнопкой → "Копировать ссылку"), не набирайте вручную.

| Тип ресурса | Как вставлять |
|-------------|---------------|
| **Канал / чат (публичный)** | `t.me/durov` или `https://t.me/durov` |
| **Канал / чат (приватный)** | `t.me/+AbCdEf_GhIj` (ссылка-приглашение) или `t.me/c/1234567890/` - ссылка вида `/c/` работает, только если аккаунт уже состоит в этом чате |
| **Пост в канале** | `t.me/durov/123` |
| **Папка Telegram** | `t.me/addlist/SLUG` (для задачи 8 - подпишет на все каналы папки) |
| **Юзернейм** | `ivan_petrov` или `@ivan_petrov` (программа поймёт оба) |
| **Ссылка на сторис** | `t.me/username/s/45` (для задачи 14.2 - клон эталонной сторис) |

## Шпаргалка: куда что вставлять

Если нужной таблицы ещё нет - программа создаст её сама при первом запуске соответствующей задачи. Заполняете вы только колонки со значком ✅.

| Задача (№) | Таблица для ваших данных | Что вводить |
|-----------|--------------------------|-------------|
| Поиск каналов (**3**) | `03 1 Поиск чатов каналов ключевые слова` | Ключевые слова (каждое с новой строки) |
| Парсер (**4**) | `04 1 Парсер пользователей ссылки` | Ссылки на чаты / каналы / посты |
| Подписка (**8**) | `08 1 Подписка на чаты каналы ссылки` | Ссылки на чаты/каналы/папки/приглашения |
| Рассылка в обсуждения (**9**) | `09 1 ... ссылки` + `09 2 ... сообщения` | Ссылки на посты + текст рекламы |
| Рассылка в чаты (**10**) | `10 1 ... ссылки` + `10 2 ... сообщения` | Ссылки на чаты + текст/ссылка на пост |
| Цитатор обсуждений (**11**) | `11 1 ... ссылки`, `11 2 ... ключевые слова`, `11 3 ... сообщения` | Каналы + ключи + ответы |
| Цитатор чатов (**12**) | `12 1 ... ссылки`, `12 2 ... ключевые слова`, `12 3 ... сообщения` | Чаты + ключи + ответы |
| Лайкер (**13**) | `13 1 Лайкер сообщений в чатах ссылки` | Ссылки на чаты |
| Масслукинг (**14.1**) | `14 1 Масслукинг сторис список` | Юзернеймы целевой аудитории |
| Масстегинг (**14.2**) | `14 2 ... список` + `14 3 ... описание` | Юзернеймы для отметок + текст сторис |
| Масстегинг - клон (**14.2**) | `14 5 Масстегинг сторис ссылки на сторис` | Ссылки на эталонные сторис `t.me/user/s/id` |
| Рассылка ЛС (**15**) | `15 1 ... список` + `15 2 ... сообщения` | Юзернеймы/номера + текст сообщения |
| Автоответчик (**16**) | `16 1 ... список чатов` + `16 2 ... автоответы` | Чаты для мониторинга + ключ → ответ |
| Инвайтер (**17**) | `17 1 ... список пользователей` + `17 2 ... ссылки на группы` | Кого приглашать + куда |
| Лидхантер (**18**) | `18 1 ... ключевые слова` + `18 2 ... принимающие группы` | Ключи перехвата + ваша группа |
| Комментинг (**19**) | `19 4 Комментинг комментарии` | Тексты/GPT-задания (см. [гл. 14](14_Промпты_для_ИИ.md)) |
| Тегер (**20**) | `20 1 ... ссылки на чаты` + `20 2 ... сообщения` | Чаты + текст с тегами |
| Чекер (**6**) | `06 1 Чекер чатов каналов ссылки` | Ссылки для проверки |
| Сканер постов (**7**) | `07 1 ... ссылки` + `07 2 ... ключевые слова` | Каналы + фильтр по словам |
| Клонер каналов (**21**) | `21 1 Клонер каналов ссылки` | ID аккаунта-админа + ссылка-источник + ссылка-приёмник |

<div class="box box-tip">
💡 <b>Хотите запустить рассылку по той же базе повторно?</b> Откройте нужную таблицу в SQLiteStudio, очистите колонку <code>Задача</code> (чтобы ячейки стали пустыми) и сохраните - база снова "свежая".
</div>

## Три важных правила

1. **Не редактируйте базу при запущенной задаче.** Сначала остановите программу, внесите правки, сохраните - потом запускайте снова.
2. **Программа сама пишет результат** в колонку `Задача` (или `Статус`): успех, `FloodWait X` (пауза от Telegram), метки-статусы. Пустая ячейка = строку можно брать в работу. Расшифровка статусов - в [главе 12](12_Результаты_и_Рекомендации.md).
3. **Рассылка в ЛС (15)** ограничена Telegram: с нового аккаунта нельзя написать много незнакомцам. Помогает подзадача "Добавить контакты" в Менеджере аккаунтов. Подробнее - в [главе 9](09_Флуды_баны_ограничения.md).
