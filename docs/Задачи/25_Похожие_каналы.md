# 25. Похожие каналы

> Раздел: **Утилиты и парсинг** · Тип: сбор базы (каналы по рекомендациям Telegram)

Аккаунт запрашивает у Telegram список похожих каналов для указанного канала и складывает находки в общую таблицу результатов поиска. Это тот самый блок "Похожие каналы", который Telegram показывает при подписке на канал.

---

## Смысл: зачем это нужно

Поиск по ключевым словам (задача 3) находит только то, что удачно названо. Половина хороших каналов туда не попадает: название не содержит вашего слова.

Рекомендации Telegram работают иначе - он сам знает, какие каналы читает одна и та же аудитория. Дали один канал конкурента - получили список каналов его же тематики, которые поиск по словам никогда бы не выдал.

Главная сила задачи - **режим 2**. После первого сбора вы запускаете задачу ещё раз, и она идёт по уже найденным каналам: каждый запуск - ещё один шаг вглубь. Из 5 стартовых ссылок за три-четыре запуска вырастают сотни тематических каналов.

<div class="box box-info">
ℹ️ Подписываться на канал не нужно - достаточно ссылки. Но объём выдачи зависит от аккаунта: обычный аккаунт видит около 10 похожих каналов, аккаунт с Telegram Premium - до 100. В логе программа пишет оба числа: сколько получено и сколько всего есть.
</div>

---

## Как это работает по шагам

1. Аккаунт берёт канал: в режиме 1 - ссылку из `03 3 Похожие каналы ссылки`, в режиме 2 - необработанный канал из `03 2 Поиск чатов каналов результаты`.
2. Запрашивает у Telegram список похожих каналов.
3. Каждый найденный канал записывается в `03 2` (без повторов).
4. В колонку `Ключевое слово` записывается канал-источник - видно, откуда пришла находка.
5. В колонку `Глубина` записывается номер шага: 1 - найден от вашей ссылки, 2 - найден на втором запуске, и так далее. Программа считает это сама.
6. Отработанный канал помечается в колонке `Обработан`, повторно он не берётся.

Один запуск - **один шаг**. Хотите глубже - запустите задачу ещё раз в режиме 2.

---

## Пошаговый запуск

1. Заполните таблицу `03 3 Похожие каналы ссылки` ссылками на каналы вашей темы.
2. В программе кликните **25 Похожие каналы**.
3. Поставьте **Режим = 1**, нажмите **"Продолжить"**, задайте задержку старта и **"Запустить"**.
4. Посмотрите на результат в `03 2`. Хотите больше - поставьте **Режим = 2** и запустите снова.
5. Режим 2 можно запускать сколько угодно раз: каждый запуск берёт ещё не обработанные каналы и идёт на шаг дальше.

## Разбор всех настроек

| Настройка | Что делает | Что ставить |
|-----------|-----------|-------------|
| **Режим (1 - По ссылкам из 03 3 / 2 - По найденным каналам из 03 2)** | Откуда брать каналы для запроса | Сначала `1`, дальше `2` |
| **Кол-во ссылок на аккаунт** | Сколько каналов обработает один аккаунт за проход | `3-5` |
| **Минимум участников в канале (0 - без проверки)** | Отсекать мелкие каналы | `0` |
| **Задержка после запроса (сек)** | Пауза между запросами к Telegram | `3-6` |
| **Кол-во одновременно работающих потоков** | Сколько аккаунтов работают параллельно | `1-3` |
| **Задержка перед выполнением следующего потока/группы потоков (сек)** | Пауза перед запуском следующего аккаунта | `15-40` |

### Подробно про важные настройки

**Режим** - главная настройка задачи.

- `1` - работа по вашему списку в `03 3`. С этого начинают.
- `2` - работа по каналам из `03 2`: по тому, что нашла эта задача в прошлые запуски, и по тому, что нашла задача 3 по ключевым словам. Вписывать ничего не нужно. Берутся только строки с типом `Канал`, у которых колонка `Обработан` пустая, поэтому каждый запуск продолжает с места остановки.

Пачка каналов в режиме 2 берётся один раз на запуск. Каналы, найденные в этом же проходе, в работу не пойдут - они дождутся следующего запуска. Именно поэтому один запуск = ровно один шаг вглубь.

**Кол-во ссылок на аккаунт** - сколько каналов обработает один аккаунт. В режиме 2 при 8 аккаунтах и значении `5-5` за один запуск разберётся до 40 каналов.

**Минимум участников в канале** - фильтр по размеру. Учтите: Telegram не присылает количество участников вместе с рекомендациями, поэтому при значении больше `0` программа делает **отдельный запрос по каждому найденному каналу**. Это сильно замедляет работу и повышает риск поймать паузу. Ставьте `0`, а базу фильтруйте потом через чекер (задача 6).

<div class="box box-tip">
💡 Начните с 5-10 ссылок на каналы конкурентов в режиме 1, затем 2-3 раза прогоните режим 2. Этого хватает, чтобы собрать несколько сотен каналов по теме.
</div>

## Куда вставлять данные

| Таблица | Кто заполняет | Что вписывать |
|---------|---------------|---------------|
| `03 3 Похожие каналы ссылки` | **Вы** | Ссылки на каналы, по одной в строку (`https://t.me/durov`, `@durov`) |
| `03 2 Поиск чатов каналов результаты` | Программа | Найденные каналы: название, ссылка, канал-источник, глубина (не трогать) |

Результаты пишутся в ту же таблицу, что и у задачи 3. Это сделано специально: подписка, парсер и клонер уже умеют брать каналы оттуда, ничего дополнительно настраивать не нужно.

Как открыть таблицы - [глава 2](../Руководство/02_Подготовка_данных.md).

## Живой пример

**Задача:** собрать все каналы по теме "инвестиции", включая те, что не находятся поиском по словам.

**Подготовка:**
1. В `03 3` вписаны 5 ссылок на известные каналы по инвестициям.

**Первый запуск:**

| Настройка | Значение |
|-----------|----------|
| Режим | `1` |
| Кол-во ссылок на аккаунт | `2-3` |
| Минимум участников | `0` |
| Задержка после запроса (сек) | `4-8` |
| Кол-во одновременно работающих потоков | `2` |

Результат: около 50 каналов в `03 2` с Глубиной `1`.

**Второй запуск:** меняете только **Режим на `2`**, остальное не трогаете. Программа проходит по этим 50 каналам и добавляет несколько сотен новых с Глубиной `2`.

**Третий запуск:** снова режим `2` - идёт по каналам с Глубиной `2` и добавляет Глубину `3`.

Останавливаетесь, когда каналов достаточно или когда находки перестают попадать в вашу тему.

---

## Статусы в таблице `03 3`

| Статус | Что значит |
|--------|-----------|
| `Собрал похожие` | Ссылка обработана, находки записаны в `03 2` |
| `Похожих нет` | Telegram не дал рекомендаций по этому каналу |
| `Ошибка ссылки` | Канал не найден, приватный или ссылка написана неверно |

## Частые ошибки

| Симптом | Решение |
|---------|---------|
| Задача сразу завершается | В `03 3` все ссылки уже обработаны или список пуст. Очистите колонку `Задача` или добавьте новые ссылки |
| Приходит только 10 каналов вместо 100 | У аккаунта нет Telegram Premium. Поставьте задачу на Premium-аккаунт |
| `Похожих нет` по многим ссылкам | Каналы мелкие или новые - Telegram по ним рекомендаций не строит. Берите крупные каналы |
| Аккаунт ловит паузу (FloodWait) | Увеличьте `Задержка после запроса (сек)` и уменьшите `Кол-во ссылок на аккаунт` |
| В результатах каналы не по теме | Так бывает на третьем-четвёртом запуске режима 2: тема расползается в соседние ниши. Остановитесь раньше |
| Работает очень медленно | Включён фильтр по участникам. Поставьте `Минимум участников` в `0` |
| В режиме `2` задача не берёт каналы | В `03 2` у всех строк заполнена колонка `Обработан` - всё уже обойдено. Добавьте новые ссылки в `03 3` и прогоните режим 1, либо очистите колонку `Обработан` |
