# 20. Тегер

> Раздел: **Инвайтинг и контент** · Тип: рассылка через упоминания

Аккаунт заходит в чаты и отправляет туда обычное на вид сообщение. Но внутри этого сообщения спрятаны **невидимые упоминания** недавно активных участников чата. Каждый упомянутый человек получает личное уведомление "вас упомянули" - и заходит посмотреть, о чём речь.

У тегера три режима, переключаются настройкой **"Тип упоминания"**:

| Режим | Что делает | Где применять |
|-------|-----------|---------------|
| **1 - скрытый пачкой** | Одно сообщение пингует сразу 5-10 человек невидимыми упоминаниями | Чужие чаты, где вы обычный участник |
| **2 - видимый @юзернейм по одному** | Отдельный пост на каждого подписчика с видимым `@юзернейм` | Свой чат, где аккаунт админ |
| **3 - постит бот** | Пост публикует ваш бот с кнопками, тегает приглашённых (🟢) из списка Инвайтера `17 1` | Свой чат, куда добавлен бот, после Инвайтера |

---

## Смысл: зачем это нужно

Обычное сообщение в чате легко пролистать. А вот персональное уведомление "вас упомянули" мало кто игнорирует - человек заходит проверить. Тегер использует это: одно сообщение в чате незаметно "пингует" сразу несколько живых участников, и каждый из них видит ваш текст.

Упоминания **невидимые** - в самом сообщении их не видно, оно выглядит как обычный текст. Пингуются только те, кто был онлайн недавно, - то есть живые, а не "мёртвые души".

<div class="box box-info">
ℹ️ Обычно в одно сообщение прячут упоминания 5-10 человек. Слишком много упоминаний в одном сообщении выглядит подозрительно и раздражает участников.
</div>

---

## Как это работает по шагам

### Режим 1 - скрытый пачкой

1. Аккаунт заходит в чат по ссылке из вашего списка.
2. Читает участников и отбирает тех, кто был онлайн недавно (сегодня, "был недавно" или прямо сейчас в сети).
3. Когда наберётся нужное количество человек - берёт случайное сообщение из вашего списка.
4. Прячет в конец сообщения невидимые упоминания всех отобранных людей.
5. Отправляет сообщение в чат. Каждый упомянутый получает уведомление "вас упомянули".
6. Делает паузу и набирает следующую группу людей.

<div class="box box-tip">
💡 Чтобы одни и те же люди не получали упоминание повторно, тегер запоминает, кого уже пингнул в этом чате.
</div>

### Режим 2 - видимый @юзернейм по одному

1. Аккаунт заходит в свой чат по ссылке из списка. **Аккаунт должен быть админом чата** - иначе список подписчиков не получить.
2. Забирает список участников чата.
3. Берёт первого подписчика, подставляет его `@юзернейм` и имя в текст поста, добавляет картинки и отправляет пост в чат.
4. Делает паузу и повторяет со следующим подписчиком.

То есть 100 подписчиков - 100 постов, текст одинаковый, упоминание в каждом своё.

**По умолчанию аккаунт обходит всех подписчиков за один проход** - настройка **"Кол-во постов на аккаунт (видимый режим)"** стоит на `Без ограничений`. 100 подписчиков - 100 постов подряд с одного аккаунта, с паузой между ними.

**Если хотите размазать нагрузку по нескольким аккаунтам** - поставьте в этой настройке лимит, например `10-20`, и увеличьте **"Кол-во циклов работающего потока/группы потоков"**. Тогда аккаунт сделает свои 10-20 постов и остановится, после цикла ссылка на чат освободится, и следующий проход продолжит с того подписчика, на котором остановились. Повторов не будет.

Пример: 100 подписчиков, лимит `10-20`, циклов `8` - за запуск обойдёте примерно всех, но постить будут разные аккаунты.

**Где в тексте будет упоминание.** В текст поста можно вписать две метки:

| Метка | Что подставится | Пример результата |
|-------|-----------------|-------------------|
| `USERNAME` | Упоминание с собакой | `@ivan_petrov` |
| `{NAME}` | Имя подписчика ссылкой на профиль, без собаки | `Иван` (кликабельное) |

```
Привет, USERNAME! Сегодня разбираем новую схему, залетай.
```

Уйдёт как: `Привет, @ivan_petrov! Сегодня разбираем новую схему, залетай.`

```
{NAME}, держи подборку - забирай, пока не удалили.
```

Уйдёт как: `Иван, держи подборку - забирай, пока не удалили.` Имя кликабельное, уведомление человек получит.

Если ни одной метки в тексте нет, упоминание допишется в конец поста.

<div class="box box-info">
ℹ️ Метки можно ставить вместе: <code>{NAME}</code> в начале для обращения по имени и <code>USERNAME</code> дальше по тексту. Второе упоминание в конец при этом не добавляется.
</div>

**Если у подписчика нет @юзернейма** - упоминание ставится по его имени и всё равно остаётся кликабельным, уведомление человек получит.

### Режим 3 - постит бот

Сообщение в чат отправляет не аккаунт, а ваш бот. Нужно это ради одного: **кнопки под постом умеют ставить только боты**. Аккаунт кнопку прикрепить не может.

Людей для тегов режим берёт не из чата, а из списка Инвайтера `17 1 Инвайтер список пользователей` - только строки с зелёным кружком 🟢, то есть тех, кого Инвайтер успешно завёл в чат. Сценарий: Инвайтером заводите людей в свой чат, затем Тегером бот их тегает.

1. Аккаунт заходит в чат по ссылке из списка и открывает пост-донор по ссылке из таблицы сообщений.
2. Бот читает список `17 1` и берёт только строки с 🟢: строки с ID как есть, строки только с юзернеймом резолвит сам. Строки с 🔴 (не приглашён, запрет на инвайт) и свободные строки пропускаются.
3. Из донора берутся текст, картинка и **кнопки**.
4. Бот публикует пост в чат пачками по настройке **"Кол-во пользователей в сообщении"**, дописав в конец невидимые упоминания людей из списка.

Каждый упомянутый получает уведомление, а под постом стоят кликабельные кнопки. Кого уже тегали в этом чате, второй раз не берут.

**Метки в тексте.** `{NAME}` и `USERNAME` работают и здесь, как в режиме 2. Если в пачке один человек (настройка `1-1`), подставится его имя или @юзернейм. Если несколько - перечисление через запятую, каждое имя ссылкой на профиль: "Иван, Пётр, Анна, залетайте". Имена аккаунт берёт из списка участников чата. Без меток пост уходит как есть, уведомления людям всё равно приходят через скрытые упоминания.

**Что нужно подготовить:**

1. Создайте бота у @BotFather и вставьте его токен в настройку **"Токен бота (режим 3)"**.
2. Добавьте бота в чат, куда будете постить, и дайте ему право отправлять сообщения.
3. Сделайте пост с кнопками в своём канале и вставьте ссылку на этот пост в таблицу `20 2 Тегер сообщения` - вместо текста.
4. Аккаунт, который работает задачу, должен иметь доступ к каналу с постом-донором.
5. Прогоните Инвайтер: у приглашённых в `17 1` появится 🟢, именно их бот и будет тегать.

<div class="box box-info">
ℹ️ Переносятся только кнопки-ссылки. Кнопки с обработкой нажатия (callback) не переносятся: нажатие уходило бы боту-автору донора, а не вашему, и кнопка молчала бы.
</div>

<div class="box box-warning">
⚠️ Упоминание от бота срабатывает, потому что человек состоит в том же чате, куда идёт пост. Тегать через бота тех, кто в чате не состоит, не получится - Telegram такое упоминание не доставит. Поэтому сначала Инвайтер, потом Тегер.
</div>

<div class="box box-tip">
💡 В один пост уходит не больше 50 упоминаний. Если поставить в настройке больше, программа сама уменьшит до 50 - при большем количестве Telegram начинает срезать упоминания.
</div>

### Картинки в постах

Положите картинки в папку `Data\Tager_Photo` (программа создаёт её сама при запуске задачи, внутри лежит инструкция). Подходят jpg, jpeg, png, webp, bmp, gif.

В настройке **"Кол-во картинок в посте (видимый режим)"** укажите, сколько картинок уходит в один пост:

- `0-0` - посты уходят без картинок (так стоит по умолчанию)
- `1-1` - к каждому посту одна случайная картинка
- `2-4` - к каждому посту от 2 до 4 картинок одним альбомом

Картинки берутся из папки случайно, поэтому посты не выглядят под копирку. Больше 10 картинок в один пост Telegram не принимает - если поставите больше, уйдёт 10.

<div class="box box-info">
ℹ️ Текст с упоминанием уходит подписью к альбому. Если текст длиннее 1024 символов, Telegram не пускает его в подпись - тогда программа отправит альбом, а следом текст отдельным сообщением. Упоминание в любом случае не потеряется.
</div>

Если папка пустая, посты всё равно уйдут - просто текстом.

**Кого уже тегнули - программа помнит между запусками.** Запустили задачу второй раз - она продолжит со следующего подписчика, а не начнёт заново. Чтобы обойти всех подписчиков с нуля, удалите папку `Data\Tager`.

<div class="box box-warning">
⚠️ Ставьте задержку побольше (от 60 сек) и не гоните все 100 постов с одного аккаунта. Серия одинаковых постов подряд - самый быстрый способ поймать паузу от Telegram.
</div>

## Пошаговый запуск

1. Заполните таблицу `20 1 Тегер ссылки на чаты` ссылками на чаты.
2. Заполните таблицу `20 2 Тегер сообщения` текстами, которые будете отправлять.
3. В программе кликните **20 Тегер**.
4. Выставьте настройки (разбор ниже) и нажмите **"Продолжить"**.
5. Введите задержку старта и нажмите **"Запустить"**.

## Разбор всех настроек

| Настройка | Что делает | Что ставить |
|-----------|-----------|-------------|
| **Кол-во ссылок на аккаунт** | Сколько чатов из списка возьмёт один аккаунт за проход | `2-4` |
| **Задержка после отправки сообщения (сек)** | Пауза между отправками сообщений | `60-180` |
| **Тип упоминания** | `1` - скрытые упоминания пачкой, `2` - видимый `@юзернейм` по одному посту, `3` - пост от бота с кнопками | `1` |
| **Токен бота (режим 3)** | Токен бота от @BotFather, от имени которого уходят посты | пусто |
| **Кол-во пользователей в сообщении** | Только для режима 1: сколько человек прятать в одно сообщение | `5-10` |
| **Кол-во постов на аккаунт (видимый режим)** | Только для режима 2: сколько постов сделает один аккаунт за проход | `Без ограничений` |
| **Кол-во картинок в посте (видимый режим)** | Только для режима 2: сколько картинок из папки `Data\Tager_Photo` уйдёт в один пост | `0-0` |
| **Кол-во одновременно работающих потоков** | Сколько аккаунтов рассылают параллельно | `1-3` |
| **Задержка перед следующим потоком (сек)** | Пауза перед запуском следующего аккаунта | `15-40` |

### Подробно про важные настройки

**Кол-во пользователей в сообщении** - это то, сколько живых участников будет "пингнуто" одним сообщением. Аккаунт набирает нужное количество активных людей и только потом отправляет сообщение с их невидимыми упоминаниями. Оптимально `5-10`: достаточно охвата, но без явного спама. В режиме 2 настройка не используется - там всегда один подписчик на пост.

**Кол-во постов на аккаунт (видимый режим)** - лимит постов для одного аккаунта в режиме 2. На `Без ограничений` (по умолчанию) один аккаунт обойдёт всех подписчиков подряд. Если поставить лимит `10-20`, аккаунт сделает 10-20 постов и остановится, а следующий продолжит с того места, где остановился первый. Так нагрузка размазывается по аккаунтам и никто не постит подряд сотню сообщений.

<div class="box box-tip">
💡 Ставьте диапазоны с разбросом ("60-180", а не "120-120") - ровный ритм выдаёт автоматизацию. Про потоки и задержки подробно - <a href="../Руководство/03_Общие_параметры_и_форматы.md">глава 3</a>.
</div>

## Куда вставлять данные

| Таблица | Кто заполняет | Что вписывать |
|---------|---------------|---------------|
| `20 1 Тегер ссылки на чаты` | **Вы** | Ссылки на чаты (`t.me/chatname`), по одной в строку |
| `20 2 Тегер сообщения` | **Вы** | Тексты сообщений, которые будут отправляться в чаты (случайный выбор) |

Как открыть таблицы - [глава 2](../Руководство/02_Подготовка_данных.md).

### Как заполнять таблицу `20 2` (тексты сообщений)

- **Готовый текст** - просто впишите сообщение. Можно несколько вариантов, программа выберет случайный.
- **Случайные варианты** - формат `{привет|здравствуйте|хай}` подставит один из вариантов случайно.
- **HIDE_URL** - добавьте эту метку в текст, чтобы убрать превью ссылки в сообщении.
- **USERNAME** - метка для режима 2: на её место встанет упоминание подписчика с собакой.
- **{NAME}** - метка для режима 2: на её место встанет имя подписчика ссылкой на профиль, без собаки.
- **Ссылка на пост** - вставьте ссылку вида `t.me/channel/123`, и в чат уйдёт копия этого поста вместе с упоминанием.
- **Задание для нейросети** - начните строку с `GPT:` и опишите задачу, тогда текст сообщения сгенерирует нейросеть.

<div class="box box-info">
ℹ️ Как писать задания-промпты для режима <code>GPT:...</code> - см. <a href="../Руководство/14_Промпты_для_ИИ.md">Промпты для ИИ</a>.
</div>

## Живой пример

**Задача:** позвать живую аудиторию из 15 тематических чатов к себе в канал.

**Подготовка:**
1. В `20 1` вставлены 15 ссылок на активные чаты.
2. В `20 2` вписаны 3 варианта сообщения со ссылкой на канал, каждое с конструкцией `{Ребят|Друзья|Привет всем}` в начале.

**Настройки:**

| Настройка | Значение |
|-----------|----------|
| Кол-во ссылок на аккаунт | `2-3` |
| Задержка после отправки сообщения (сек) | `90-240` |
| Кол-во пользователей в сообщении | `6-9` |
| Потоки | `2` |

**Результат:** аккаунты заходят в чаты, набирают по 6-9 недавно активных участников и отправляют сообщение с их невидимыми упоминаниями. Каждый получает уведомление "вас упомянули", заходит проверить и видит приглашение в ваш канал.

## Частые ошибки

| Симптом | Решение |
|---------|---------|
| Задача сразу завершается | Пуста таблица `20 1` или `20 2`, либо все ссылки уже обработаны. Заполните таблицы или очистите колонку `Задача` |
| В таблице `20 1` статус "Нерабочая ссылка" | Ссылка мёртвая, неверная или ведёт на канал вместо чата. Проверьте ссылку |
| Сообщение отправляется, но никого не пингует | В чате мало недавно активных участников - тегер не набирает нужное количество. Уменьшите "Кол-во пользователей в сообщении" или выбирайте более живые чаты |
| Аккаунт быстро ловит паузу (FloodWait) | Увеличьте "Задержку после отправки сообщения" и уменьшите потоки |
| В режиме 2 в логе "Нет участников" | Аккаунт не админ этого чата или список участников скрыт настройками чата. Выдайте аккаунту права админа |
| В режиме 2 постов вышло меньше, чем подписчиков | Сработал лимит "Кол-во постов на аккаунт". Поставьте `Без ограничений` или увеличьте "Кол-во циклов работающего потока/группы потоков" - каждый следующий цикл добирает остальных |
| В режиме 2 задача ничего не постит, хотя подписчики есть | Всех уже тегнули в прошлых запусках. Удалите папку `Data\Tager`, чтобы пройти круг заново |
| В режиме 2 посты уходят без картинок | Настройка "Кол-во картинок в посте" стоит на `0-0`, либо папка `Data\Tager_Photo` пуста. В логе будет строка "Папка картинок пуста" |
| Вместо имени в посте слово NAME | Метку пишите строго как `{NAME}`, заглавными и в фигурных скобках |
| В логе "профиль недоступен для упоминания" | Редкий случай: Telegram не отдал профиль этого участника, тегнуть его нельзя. Программа пропускает такого человека и идёт к следующему, пост впустую не тратится |
