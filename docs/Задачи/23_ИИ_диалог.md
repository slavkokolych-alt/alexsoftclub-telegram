# 23. ИИ диалог аккаунтов

> Раздел: **AI-ОБЩЕНИЕ** · Тип: оживление чата нейросетью

Несколько ваших аккаунтов **оживляют чат**: пишут в один общий чат живые реплики, которые генерирует нейросеть, отвечают друг другу и на людей, и при желании мягко подводят участников к переходу в личку.

<div class="box box-info">
ℹ️ Писать можно <b>только в группу или чат обсуждений под каналом</b>. В сам канал (где пишут только админы) задача писать не умеет.
</div>

---

## Смысл: зачем это нужно

Живой на вид разговор в чате привлекает внимание лучше любой рекламы. Ваши аккаунты обсуждают тему, спорят, делятся "опытом" - и настоящие участники сами включаются и пишут вам в личку. При включённой **дуге** разговор постепенно ведёт к цели (боль - решение - призыв в личку), при **оркестре** у каждого аккаунта своя роль (новичок, эксперт, скептик, довольный клиент).

Это подробная тема - вся практика вынесена в отдельные главы:

- **Как настроить, запустить и что делает дуга/оркестр** - [глава 15](../Руководство/15_ИИ_диалог_аккаунтов.md)
- **Промпты и файлы `Data/AI/`** (что писать нейросети) - [глава 14](../Руководство/14_Промпты_для_ИИ.md)
- **Подключение нейросети** (URL, ключ, модель) - [глава 13](../Руководство/13_Настройка_LLM_API.md)

## Пошаговый запуск (кратко)

1. В главном меню **мышкой** откройте раздел **AI-ОБЩЕНИЕ** - задача **`23` ИИ диалог аккаунтов**.
2. Впишите чаты в таблицу `23 0 ИИ диалог чаты` - по одной ссылке в строку.
3. Заполните настройки (список ниже).
4. Убедитесь, что аккаунты **в чате** и **освобождены** в задаче [22 Таблица аккаунтов](22_Таблица_аккаунтов.md).
5. Подготовьте папку `Data/AI/` - см. [главу 14](../Руководство/14_Промпты_для_ИИ.md).
6. Нажмите **`Продолжить`**.

Подробный пошаговый разбор с примером диалога - в [главе 15](../Руководство/15_ИИ_диалог_аккаунтов.md).

## Настройки задачи

| Настройка | Что делает |
|-----------|-----------|
| **Тема диалога** | Общая рамка разговора для всех аккаунтов |
| **Кол-во чатов за запуск** | Сколько чатов из списка взять за один запуск. "Без ограничений" - весь список |
| **Задержка между чатами (сек)** | Пауза после отработки чата, перед переходом к следующему |
| **Кол-во сообщений на аккаунт** | Сколько реплик отправит один аккаунт за прогон |
| **Задержка после сообщения (сек)** | Пауза между своими репликами одного аккаунта |
| **Включить дугу** | Пошаговый сценарий: intro - pain - offer - cta |
| **Включить оркестр** | Разные роли аккаунтов (новичок, эксперт, скептик, клиент) |
| **Отвечать только своим аккаунтам** | Reply только коллегам из запуска |
| **Отвечать живым участникам** | Reply на посторонних людей в чате |
| **Приоритет ответа (1 / 2 / 3)** | `1` - сначала живые, `2` - сначала свои, `3` - любой неотвеченный |
| **URL API агрегатора / LLM API ключ / LLM модель** | Подключение нейросети - см. [главу 13](../Руководство/13_Настройка_LLM_API.md) |

Полное описание каждой настройки с рекомендациями для старта - в [главе 15](../Руководство/15_ИИ_диалог_аккаунтов.md).

<div class="box box-tip">
💡 Задержки задаются <b>в секундах</b> и с разбросом ("60-120", а не "60-60") - ровный ритм выдаёт автоматизацию.
</div>

## Куда вставлять данные и где смотреть результат

| Таблица | Кто заполняет | Что там |
|---------|---------------|---------|
| `23 0 ИИ диалог чаты` | Вы | Список чатов. Аккаунты обходят их по очереди, чат за чатом |
| `23 1 ИИ диалог отчеты` | Программа | Реплики, которые реально ушли в чат (аккаунт, текст, ссылка на сообщение) |
| `23 2 ИИ диалог дуга` | Программа | Текущая фаза дуги для пары "аккаунт + чат" (сбрасывают удалением строк) |
| `23 3 ИИ диалог сообщения чата` | Программа | Журнал всех реплик в чате - свои и чужие |

Как открыть таблицы - [глава 2](../Руководство/02_Подготовка_данных.md). Разбор колонок - в [главе 15](../Руководство/15_ИИ_диалог_аккаунтов.md).

## Частые ошибки

| Симптом | Решение |
|---------|---------|
| "Пустой список: 23 0 ИИ диалог чаты" | Добавьте ссылки на чаты в таблицу `23 0 ИИ диалог чаты` |
| Чат помечен "❌ Нет доступа" | Аккаунты не смогли писать в этот чат: нет доступа, бан или это канал |
| В базе текст есть, в чате пусто | Указан **канал**, а не группа. Дайте группу или чат обсуждений |
| "Нет свободных аккаунтов" | Освободите аккаунты в задаче [22 Таблица аккаунтов](22_Таблица_аккаунтов.md) |
| Ошибка LLM / пустой ответ | Проверьте ключ, модель и баланс - [глава 13](../Руководство/13_Настройка_LLM_API.md) |
| Однотипные длинные ответы | Ужесточите промпт - [глава 14](../Руководство/14_Промпты_для_ИИ.md) |
