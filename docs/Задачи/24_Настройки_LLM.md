# 24. Настройки LLM API

> Раздел: **AI-ОБЩЕНИЕ** · Тип: общие настройки нейросети (один раз для всех задач)

Здесь **один раз** подключается нейросеть, которую потом используют **все** ИИ-задачи программы. Настроили три поля - и нейросеть работает везде, повторно вписывать ключ в каждую задачу не нужно.

<div class="box box-info">
ℹ️ Это глобальные настройки. Один и тот же ключ обслуживает все задачи с ИИ на этом ПК.
</div>

---

## Где используется

| Задача | Как задействует нейросеть |
|--------|---------------------------|
| **19 Нейрокомментинг** | Пишет комментарии под постами |
| **23 ИИ диалог аккаунтов** | Генерирует реплики в чат |
| **10 Рассыльщик / 12 Цитатор** | Вставка `GPT:` в сообщениях |
| **8 Подписка на чаты/каналы** | Авто-решение Rose-капчи (нужна модель, которая "видит" картинки, например `gpt-4o`) |

Остальные модули с `GPT:` (тегер и т.п.) работают через лицензионный прокси AlexSoftClub - для них ключ не обязателен.

---

## Куда зайти в программе

1. Запустите **AlexSoftClub** двойным щелчком по `.exe`.
2. В главном меню **мышкой** щёлкните раздел **AI-ОБЩЕНИЕ** - пункт **`24` Настройки LLM API**.
3. Заполните три поля (ниже) и сохраните.

---

## Три поля

| Поле в программе | Что вставить |
|------------------|--------------|
| **URL API агрегатора** | Адрес API сервиса **без** `/chat/completions` (можно с `/v1` в конце) |
| **LLM API ключ** | Ключ из личного кабинета выбранного сервиса |
| **LLM модель** | Точный id модели из документации сервиса |

<div class="box box-tip">
💡 Программа сама допишет путь <b>/chat/completions</b> - вставляйте URL как есть.
</div>

Подробная пошаговая инструкция, готовая **таблица сервисов** (OpenAI, OpenRouter, VseLLM, DeepSeek и др. с точными URL) и разбор ошибок - в [главе 13](../Руководство/13_Настройка_LLM_API.md).

---

## Если не работает

| Симптом | Что проверить |
|---------|---------------|
| Сразу пишет про ключ или URL | Заполнены `URL API агрегатора` и `LLM API ключ` |
| Пустой ответ ИИ | Неверная `LLM модель` или нет денег на балансе сервиса |
| Ошибка HTTP 401 | Неверный или просроченный ключ |
| Ошибка HTTP 404 | Неверный id модели для этого URL |

Полная таблица ошибок и примеры настройки конкретных сервисов - [глава 13](../Руководство/13_Настройка_LLM_API.md).
